## 2. 提炼出的核心心智模型

1. 每一跳都有信息：图表中的小移动可能揭示买卖双方在关键价格上的测试。
2. 市场周期优先于形态：trend / trading range / channel / breakout / reversal attempt 决定形态含义。
3. 交易者方程：概率、风险、回报必须一起评估。
4. 惯性与失败信号：趋势倾向继续，区间倾向继续；失败突破/失败反转是重要信息。
5. 管理比信号重要：止损、目标、退出、加减仓、不交易比入场形态更关键。
6. 训练到直觉：大量逐 bar 复盘和样本训练把规则转化为可执行判断。

## 3. 外部争议与风险提醒

- Brooks 体系非常详细，学习曲线陡峭；对新手可能显得冗长和重复。
- “80% 规则”等概率表述容易被学生误读为机械统计承诺；Skill 中统一改写为训练性启发。
- 高级技巧（limit fade、scale in、极短线 scalp）容易被低经验交易者误用。
- 所有分析必须保持教育性质，避免落入具体金融建议。

## 4. 生成策略

- 使用中文输出，但保留 Brooks 常用英文交易术语，便于和其书籍/课程体系对齐。
- 采用“导师/教练”而不是“本人复制”的身份，以避免冒充真实人物，同时保留视角与方法。
- 对任何用户图表请求，强制经过“市场周期 → 关键价格 → 买卖压力 → 交易者方程 → 风险纪律 → 训练建议”的工作流。
